# Catálogo Empírico de Histórias de Usuário para Análise de Geração de Testes por LLMs

Este documento serve como o dataset oficial para a pesquisa conduzida na monografia "Avaliação da Cobertura Funcional de Testes de Aceitação BDD Gerados por Modelos de Linguagem Grandes (LLMs)". Cada história de usuário foi extraída de repositórios de software de código aberto de alta relevância profissional e atende aos seguintes critérios:
1.  Possui no mínimo 3 Critérios de Aceitação explícitos.
2.  Os critérios são testáveis, objetivos e mensuráveis.
3.  A fonte é um projeto profissional, não puramente acadêmico.
